CarLife на Android Box — обновление runtime через Magisk

Для существующей рабочей установки CarLife на TBox Ultra 1 / SM6350 / Android 15.
Это кандидат с раздельными MEDIA/TTS, медиаданными, манёврами из уведомлений
Яндекса, голосовым распознаванием и ограниченной очередью видео. На физическом
боксе эта сборка ещё не принята; слышимость и поддержку распознавателя проверяем
после установки. Разрешение оставлено 720p.

1. Скопируйте ZIP с "update" в названии на бокс.
2. Magisk → Модули → Установить из хранилища → выберите ZIP.
3. Дождитесь "Staged" / успешного завершения и нажмите "Перезагрузка".
   Во время установки текущий CarLife продолжает работать. После перезагрузки
   модуль один раз остановит прежний runtime, обновит файлы и запустит CarLife
   через существующий init. Возможно одно переподключение изображения.
4. Magisk → CarLife runtime update → Действие: проверьте итог применения.
   Затем проверьте музыку, подсказку Яндекса, Home/Back и изображение.

Boot, системные APK, настройки ADB, USB-режим и выбранный AA/CarPlay/CarLife
этот пакет не меняет. Нового патча boot и повторной первоначальной установки
CarLife не требуется. Последующие загрузки используют прежний ранний init;
service.sh нужен только для применения ещё не завершённого обновления.

Возврат: установите ZIP с "rollback" тем же способом и перезагрузите бокс.
Он возвращает runtime, сохранённый перед ПЕРВЫМ обновлением этим установщиком,
сохраняя boot и текущий выбор режима. Backup и журнал остаются в
/data/adb/carlife-runtime-update/. Это откат обновления, не удаление CarLife.
Выключение/удаление модуля Magisk само по себе уже заменённые файлы не откатывает.

Если установка или применение сообщили ошибку, сохраните журнал и состояние
кнопки «Действие». Несовместимая установка не превращается в новую прошивку.
Не отключайте питание в момент применения. Отдельный устойчивый источник
питания, использованный на стенде Honda, подходит и для этого обновления.

Этот ZIP не устанавливает CarLife на чистый бокс. Для первой установки нужен
отдельный универсальный установщик под совместимую прошивку.
