Один ZIP для совместимого TBox Ultra 1 / SM6350 / Android 15.

Magisk -> Модули -> Установить из хранилища -> этот ZIP -> одна перезагрузка.
Установщик сам определяет чистую установку, прежний universal или поддерживаемый
native runtime. Настройки устанавливаются одновременно. При первой установке
сохраняется и патчится только собственный активный boot бокса. При обновлении
boot и сохранённые настройки не меняются. Нужен уже работающий Magisk/root.

Откат без загрузки другого файла:
su -c '/data/adb/magisk/busybox sh /data/adb/carlife-package/control.sh rollback'
Затем перезагрузитесь. Для universal возвращается исходный boot и удаляется
CarLife. Для прежней ручной интеграции возвращаются точные runtime/настройки
ДО ПЕРВОЙ установки объединённого ZIP; прежний CarLife остаётся установленным.
Резервные копии сохраняются в /data/adb/carlife-package и каталогах backend.

Для просмотра состояния замените rollback на status. Не удаляйте резервные
копии. На первой установке обеспечьте стабильное питание во время записи boot.
Несовместимая прошивка отклоняется без изменения защиты. Чистая установка на
втором физическом боксе ещё не принята; офлайн-тесты её не заменяют.
