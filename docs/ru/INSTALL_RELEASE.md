# Установка, обновление и откат usb-call-lab2

**ЭТА СБОРКА ЕЩЁ НЕ ТЕСТИРОВАЛАСЬ С АВТОМОБИЛЬНЫМ ГУ.** Это предварительный релиз для тестирования; прежние результаты Honda не являются приёмкой этой сборки.

[English](../INSTALL_RELEASE.md) · [Подробная инструкция](MAGISK_INSTALLER.md) · [Состояние функций](CARLIFE_SERVICES_STATUS.md)

**Один файл: `Carlife_on_box-TBox-Ultra-2026.10.16-usb-call-lab2.zip`.** Скачайте его из [предварительного релиза](<https://github.com/SadykovIV/Carlife_on_box/releases/tag/v2026.10.16-usb-call-lab2>).

SHA256: `957c5b2a8a471aced1d6349c29d764f52dde95bcbf12557b67b8941381dae0b4`.

В сборке подключён звук звонков через USB без зависимости от Bluetooth и убраны лишние команды статуса. Обновление стендового бокса, 56 наборов JVM-тестов, 133 host-теста и синтетические проверки двустороннего звука/mute/переподключения с Mac прошли. Настоящие SIM/VoIP-звонки, физический микрофон ГУ и приёмка этой сборки на Honda ещё впереди. Чистая установка на втором физическом TBox не проверена.

1. Нужен совместимый **TBox Ultra 1 / SM6350 / Android 15** с работающим Magisk/root. Для первой установки — Magisk 30.7+, уже разблокированный загрузчик и существующий permissive эталонной прошивки. Установщик проверяет OEM-файлы и не меняет защиту.
2. Сверьте ZIP с checksum релиза. Обеспечьте стабильное питание и выберите файл в **Magisk → Модули → Установить из хранилища**.
3. Перезагрузитесь один раз. Один ZIP обслуживает чистую установку, прежний universal и поддерживаемую ручную интеграцию. OEM-настройки включены. При чистой установке выбраны **Baidu CarLife** и видео **По запросу ГУ**; обновление сохраняет выбор.

Только первая установка сохраняет и патчит собственный активный boot; обновления runtime его не меняют. Перепрошивать весь бокс или извлекать boot на компьютер не нужно. Для обслуживания сохраните Wi-Fi ADB или резервный экран: USB в CarLife обслуживает ГУ.

Для состояния или отмены пакета выполните в Android-терминале с root либо существующем ADB shell:

```sh
su -c '/data/adb/magisk/busybox sh /data/adb/carlife-package/control.sh status'
su -c '/data/adb/magisk/busybox sh /data/adb/carlife-package/control.sh rollback'
```

После успешного отката перезагрузитесь. **Чистая/universal:** возвращается исходный boot, управляемый CarLife удаляется. **Прежняя ручная интеграция:** возвращаются точные runtime/UI до первого объединённого ZIP; прежний CarLife и boot остаются. В обоих случаях возвращается прежнее состояние OEM overlay. Отдельный ZIP отката не нужен.

Сохраните `/data/adb/carlife-package/` и резервные копии backend. Выключение/удаление одного модуля — не полный откат. Конфликты и границы восстановления — в [подробной инструкции](MAGISK_INSTALLER.md). Прежние инструкции r6/r7 с несколькими файлами сохранены как история и к объединённому пакету не применяются.
