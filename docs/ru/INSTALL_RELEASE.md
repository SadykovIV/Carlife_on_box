# Установка и откат r6

[English](../INSTALL_RELEASE.md) · [Скачать релиз](https://github.com/SadykovIV/Carlife_on_box/releases/tag/v2026.10.15-r6)

Выберите пакет для своей установки. **Не смешивайте два семейства установщиков.**

| Файл релиза | Назначение |
| --- | --- |
| `Carlife_on_box-TBox-Ultra-1-first-install-2026.10.15-r6.zip` | Первая установка на совместимый бокс; также обновляет установки, созданные этим установщиком. |
| `Carlife_on_box-TBox-Ultra-1-update-2026.10.15-r6.zip` | Обновление runtime существующей интеграции, установленной вручную на тестовом боксе. |
| `Carlife_on_box-TBox-Ultra-1-rollback-2026.10.15-r6.zip` | Возврат после такого обновления runtime; **не** полное удаление и не откат первой установки. |

Первое семейство отображается в Magisk как **Baidu CarLife on Android Box** (`carlife_on_box`). Для его дальнейших обновлений используйте тот же first-install ZIP новой версии. Модуль обновления прежней интеграции — **CarLife runtime update** (`carlife_runtime_update`).

## Первая установка

Поддерживаемый профиль: TBox Ultra 1, SM6350, Android 15 / SDK 35, совместимые OEM-файлы запуска, работающий Magisk **30.7+**, разблокированный загрузчик и **уже permissive** эталонная прошивка. Установщик проверяет совместимость; сам он не разблокирует устройство и не меняет защиту.

1. Скачайте first-install ZIP и сверьте SHA256 с файлом `SHA256SUMS` релиза.
2. Обеспечьте стабильное питание. Откройте **Magisk → Модули → Установить из хранилища**, выберите ZIP и дождитесь успешного завершения.
3. Перезагрузите бокс один раз и подключите к готовому CarLife ГУ. **При первой установке выбран Baidu CarLife**; последующий сохранённый выбор остаётся.

ZIP сохраняет и патчит собственный активный boot непосредственно на боксе. Чужого boot-образа внутри нет; вся прошивка не перепрошивается. Следующие обновления runtime сохраняют первую резервную копию и не перезаписывают boot. Настройки ADB сохраняются; USB используется для проекции, поэтому для обслуживания оставьте Wi-Fi ADB или резервный экран. Третий пункт в штатное меню AA/CarPlay этот ZIP не добавляет.

## Обновление прежней ручной интеграции

Установите update ZIP через **Magisk → Модули → Установить из хранилища** и перезагрузитесь. **CarLife runtime update → Действие** показывает результат. Существующая загрузочная интеграция сохраняется.

## Откат

**Семейство первой установки:** выполните в Android-терминале с root или существующем ADB shell:

```sh
su -c '/data/adb/magisk/busybox sh /data/adb/carlife-on-box/manager.sh rollback'
```

После сообщения об успешном восстановлении перезагрузите бокс. Вернётся его точный boot до установки, включая прежний Magisk; CarLife удалится. Альтернатива: **Magisk → Удалить**, перезагрузка для выполнения удаления, затем ещё одна для загрузки восстановленного boot. Сохраните резервные копии в `/data/adb/carlife-on-box/`.

**Прежняя интеграция:** установите rollback ZIP через Magisk и перезагрузитесь. Вернётся первый сохранённый runtime; интеграция CarLife и boot останутся. Отключение/удаление модуля доставки само по себе не отменяет применённые файлы.

## Что проверено

Первая установка прошла **офлайн-проверки; аппаратная приёмка впереди**. Обновление r6, прямое USB-видео и PCM проверены на тестовом боксе с Mac HU; финальную r6 ещё предстоит повторить на Honda. Подробности: [первая установка](MAGISK_INSTALLER.md) и [обновление runtime](MAGISK_RUNTIME_UPDATE.md).
