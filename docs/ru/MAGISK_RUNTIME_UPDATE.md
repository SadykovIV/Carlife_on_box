# Обновление существующего CarLife через Magisk

[English — основная инструкция](../MAGISK_RUNTIME_UPDATE.md)

Этот пакет обновляет уже установленный `boot-native-v1-20261014` на поддерживаемой прошивке TBox Ultra 1 / SM6350 / Android 15, включая нынешний стендовый бокс, настроенный вручную. Это отдельный пакет обновления. Boot, resolver, USB-observer, selector, сохранённый режим и настройки ADB сохраняются.

## Проверенный результат — 2026.10.15-r6

Обновление r6 установлено через Magisk на существующий стендовый бокс. После перезагрузки оно применилось автоматически с `RESULT=APPLIED`; повторный ручной запуск manager не потребовался. Затем **90-секундная сессия native USB с Mac HU декодировала 2 591 кадр без ошибок декодера**. Исходный boot, первая резервная копия рабочего runtime и существующая интеграция сохранены.

Отдельный 60-секундный тест V2 подтвердил регистрацию media/context/navigation и готовность голосового сервиса, декодировал 1 782 кадра 1280×720 и получил 3 147 пакетов MEDIA с 12 084 480 байтами PCM, содержащими ненулевые отсчёты. Ошибок данных и потерь PCM не записано. **Проверка завершения первой сессии V2 не прошла**: `NATIVE_RX_DRAIN_NOT_QUIESCENT` — после video PAUSE поток MEDIA продолжался и превысил срок ожидания завершения 3,5 секунды. Регистрация сервисов и передача видео/аудио подтверждены; эта первая попытка V2 не объявляется PASS. Предыдущий тест V1 завершился штатно.

Отдельный повтор V2 **прошёл, включая завершение (exit 0)** после изменения Mac HU: PAUSE_MEDIA отправляется перед VIDEO_PAUSE. За 29,564 секунды активного видео декодировано 890 кадров 1280×720 и получено 1 323 пакета MEDIA (5 080 320 байт PCM с ненулевыми отсчётами), без ошибок и потерь PCM. Потоки остановились за 0,571 секунды; ожидающих данных и оставшихся worker не было. **Установленный MD и ZIP r6 не менялись.** Повтор подтвердил исправление завершения на стороне HU; исходный неудачный опыт сохранён выше.

Пройдены **41 сценарий жизненного цикла установщика, 13 тестов сборщика ZIP и 43 JVM-набора MD**. Это проверка данной поддерживаемой установки, а не всех прошивок TBox и магнитол.

Владелец подтвердил музыку и приглушение музыки при навигационных подсказках на Honda с прежним кандидатом r3, использующим тот же аудиокод. **Финальная r6 пока проверена на Mac HU; повторного теста на Honda не было.** Медиаданные, реальные манёвры Яндекса и распознавание микрофона ГУ требуют отдельных проверок приложения и магнитолы.

Результат отката ограничен: пакет r4 вернул сохранённый baseline на устройстве **после ручного повторного запуска manager**, потребовавшегося из-за прерванной попытки. Rollback ZIP r6 повторно на устройстве не запускали. Его автоматический откат покрыт тестами, но аппаратный PASS автоматического отката r6 не заявляется.

## Установка

1. Скопируйте `Carlife_on_box-TBox-Ultra-1-update-2026.10.15-r6.zip` на бокс.
2. **Magisk → Модули → Установить из хранилища** — выберите ZIP.
3. Дождитесь успешного завершения и один раз перезагрузите бокс при стабильном питании.
4. **CarLife runtime update → Действие** показывает результат применения. Проверьте видео/ввод, музыку и подсказку навигатора на ГУ.

Установка сохраняет текущую сессию. На следующей загрузке модуль проверяет транзакцию, останавливает прежний runtime, проверяет завершение процессов, заменяет MD/controller и последним checksum, затем запускает существующий init-сервис, если выбран CarLife. В эту первую загрузку возможно одно переподключение. Последующие старты идут прежним ранним init; service модуля обрабатывает только незавершённое обновление и выходит.

В кандидате включены раздельные MEDIA/TTS, медиаданные, манёвры из уведомлений Яндекса, распознавание микрофона ГУ и ограниченная очередь видео. Для начала оставлен 720p. [Функции и границы приёмки](NATIVE_CANDIDATE.md): успешная установка сама по себе не доказывает слышимость или поддержку внешнего PCM распознавателем.

## Возврат предыдущего runtime

Установите `Carlife_on_box-TBox-Ultra-1-rollback-2026.10.15-r6.zip` тем же способом и перезагрузите бокс. Вернётся собственный runtime устройства, сохранённый **перед первым обновлением этим пакетом**. CarLife не удаляется, штатный boot не возвращается, выбранный режим не сбрасывается. Первая резервная копия и журналы остаются в `/data/adb/carlife-runtime-update/`.

Выключение или удаление модуля само по себе заменённые файлы не откатывает: используйте rollback ZIP. При ошибке сохраните журнал установки и вывод «Действие»; backup не удаляйте. После прерванной записи продолжение/откат допускаются только для файлов с записанными старыми или новыми хешами; внешние изменения не перезаписываются.

Пакет не прошивает разделы, не меняет защиту и не переводит существующую установку под управление универсального установщика. Для чистого бокса остаётся отдельная первоначальная установка. Команда сборки и тестов — в [English-инструкции](../MAGISK_RUNTIME_UPDATE.md#build).
