# Установка и откат видеонастроек r7

[English](../INSTALL_VIDEO_SETTINGS.md) · [Скачать r7](https://github.com/SadykovIV/Carlife_on_box/releases/tag/v2026.10.15-r7)

Обновление для **уже работающей поддерживаемой OEM-интеграции** на TBox Ultra 1 / SM6350 / Android 15 с модулями `carlife_runtime_update` и `carlife_oem_selector_v1`. Существующие boot и контроллер запуска сохраняются. Это не первоначальная установка на чистый бокс и не обновление отдельного семейства `carlife_on_box`.

Для первой установки остаётся отдельный [комплект r6 с инструкцией](https://github.com/SadykovIV/Carlife_on_box/releases/tag/v2026.10.15-r6). Не устанавливайте поверх него legacy updater и OEM overlay из r7: такое сочетание ещё не интегрировано и не проверено. Исходники r7 содержат изменения видео для дальнейшей интеграции.

## Обновление существующей поддерживаемой установки

1. Скачайте **Carlife_on_box-OEM-video-settings-2026.10.15.zip** и **Carlife_on_box-TBox-Ultra-1-update-2026.10.15-video4.zip**. Проверьте файлы по `SHA256SUMS`.
2. В **Magisk → Модули → Установить из хранилища** установите ZIP настроек OEM. Пока не перезагружайте.
3. Установите ZIP runtime `video4`. После успешной установки обоих файлов выполните одну перезагрузку и дождитесь применения обновления.

Название `video4` сохранено у точного проверенного пакета, опубликованного в r7: его байты совпадают с установленной на стенде сборкой. Для интерфейса и поддержки настроек нужны оба ZIP. Сохраните резервные копии и имеющийся доступ для обслуживания.

Откройте **Настройки → Оригинал → Переключение исходного режима подключения автомобиля → Параметры Baidu CarLife**. Выберите разрешение и FPS, сохраните и переподключите CarLife. Сохранение не прерывает текущую сессию. **По умолчанию → Сохранить** выбирает **По запросу ГУ** для обоих полей; отсутствие или некорректное значение даёт тот же результат. Авто-FPS принимает запрос до 30 FPS, иначе использует 30 FPS. Ручные 60 FPS и широкие режимы остаются экспериментальными. Разрешение видеопотока не меняет DPI Android.

## Возврат 720p или откат обновления

Чтобы сохранить новую сборку и вернуть ранее проверенный режим, выберите **1280×720 / 30 FPS** и переподключите CarLife. Через действующий ADB:

```sh
adb shell settings put global carlife_video_config v1:720p:30
```

Для точного возврата runtime r6 и OEM selector v5:

1. Установите **Carlife_on_box-OEM-selector-v5-baseline.zip** через Magisk; пока не перезагружайте.
2. Установите **Carlife_on_box-TBox-Ultra-1-update-2026.10.15-r6.zip**, затем перезагрузите один раз. Пакет `update` здесь намеренно возвращает точные байты r6.
3. Удалите два добавленных параметра через действующий ADB:

```sh
adb shell settings delete global carlife_video_config
adb shell settings delete global carlife_video_status
```

Не подменяйте этот комплект общим runtime `rollback` ZIP: он может вернуть первый backup, который старше r6. Выключение модуля доставки не отменяет уже применённые файлы. Это откат видеонастроек, а не удаление первоначальной интеграции CarLife. Подготовленный полный откат r6+selector не применялся повторно в данном тесте.

## Проверки и состав

Итоговая сборка прошла проверку на реальном боксе с Mac HU через прямой USB: автоматические 720p и 1080p, Defaults/сохранение через интерфейс, Home, тач, RESET и независимое декодирование H.264. Для 1080p30 измерено примерно 29,95–30 FPS. Honda в 1080p, 60 FPS и широкие режимы ещё не приняты; звук заново не проверялся в этой задаче по видео. Подробнее: [видеонастройки](VIDEO_SETTINGS.md), [результаты r7](../RELEASE_R7_VALIDATION.md).

OEM overlay содержит изменённые OEM-приложения для точно проверенной прошивки. Эти бинарники отделены от собственных исходников Apache-2.0. Ключи подписи, полная прошивка, boot-образ и записи с устройства не публикуются. [Уведомления о сторонних компонентах](../../THIRD_PARTY_NOTICES.md).
