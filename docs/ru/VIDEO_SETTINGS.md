# Параметры видео CarLife

[English](../en/VIDEO_SETTINGS.md)

Статус: обновлённый интерфейс настроек и поддержка параметров в MD проверены на боксе через прямой USB CarLife и ввод по протоколу CarLife. Необходимо обновить **и MD, и модуль настроек**. Параметры опубликованы в **r7** для существующей поддерживаемой OEM-интеграции; см. [установку и откат](INSTALL_VIDEO_SETTINGS.md).

Последняя сборка video4 использует запрос ГУ, если настройки ещё не сохранены. Переход с явно выбранного 1080p через **По умолчанию → Сохранить** проверен: записывается `v1:auto:auto`. Проверки прямого USB на боксе:

| Проверка | Результат |
| --- | --- |
| Авто, ГУ запрашивает 1280×720 / 30 | 3394 кадра за 113,1 секунды, 30 FPS |
| Авто, новая сессия ГУ запрашивает 1920×1080 / 30 | 3682 кадра за 123,229 секунды; 29,948598 / 29,999606 FPS по PTS; RESET проверен, Home и перетаскивание работают, ошибка сессии — null |
| Предыдущая проверка ручного режима 1920×1080 / 30 | 9000 кадров примерно за 300,84 секунды; 29,95–30 FPS по PTS, H.264 Level 4, RESET проверен |
| Предыдущая активная проверка video3 | 7855 кадров за 262,051 секунды; прошли кодированные видеокадры размером до 626 КиБ |

Через интерфейс также сохранён режим 1920×1080 / 15 FPS: после перезагрузки MD прочитал `v1:1920x1080:15`, хотя ГУ запрашивало 1280×720 / 30 FPS. Это результаты стенда Mac HU, а не приёмка на Honda. Приёмка 60 FPS и широких профилей на физическом ГУ пока не выполнена.

## Изменение разрешения и частоты кадров

1. Откройте **Настройки → Оригинал → Переключение исходного режима подключения автомобиля**.
2. В открывшемся диалоге нажмите **Параметры Baidu CarLife**.
3. Выберите разрешение видеопотока и целевую частоту кадров, затем нажмите **Сохранить**.
4. Переподключите CarLife. Само сохранение не прерывает текущую сессию, не меняет выбранный протокол и не перезагружает бокс.

По умолчанию выбрано **По запросу ГУ**. Также доступны явные размеры 1280×720, 800×480, 1920×1080, 1280×480, 1728×648, 1920×720 и 2240×976. **По запросу ГУ** использует размеры, запрошенные ГУ; при явном выборе размера MD запрашивает этот видеорежим. Конкретное ГУ или энкодер могут поддерживать не все варианты. Строка **Согласованный режим** читает последнее опубликованное состояние согласования при открытии диалога. Это не измеренный FPS и не индикатор активной сессии; после перезагрузки некоторое время может оставаться прежнее значение. Чтобы прочитать новое состояние, откройте диалог повторно.

Частота кадров: **По запросу ГУ** (по умолчанию), **15**, **30** или **60 FPS**. Авто FPS использует корректный запрос ГУ до 30 FPS; если корректного запроса нет, используется 30 FPS. Явно выбранное значение является целевым; последующий запрос ГУ может снизить частоту.

**60 FPS — экспериментальный режим.** Проверяемый бокс сейчас объявляет режим Android-дисплея 30 Гц. Настройка энкодера на 60 FPS сама по себе не создаёт 60 разных кадров в секунду у такого источника.

Эти параметры меняют видеовыход. Они не меняют DPI Android, масштаб интерфейса или калибровку тача. Преобразование координат продолжает использовать согласованную геометрию видео. Один лишь выбор широкого видеокадра не перестраивает рабочий стол Android и не гарантирует исчезновения полей.

## Значения по умолчанию и возврат рабочего режима

Откройте **Параметры Baidu CarLife**, нажмите **По умолчанию**, затем **Сохранить** и переподключите CarLife. Для разрешения и частоты кадров будет выбрано **По запросу ГУ**. Кнопка «По умолчанию» меняет выбор в диалоге; запись выполняется только после «Сохранить». «Отмена» оставляет сохранённые настройки прежними.

Для диагностики пара хранится атомарно в Android `Settings.Global`, ключ `carlife_video_config`, например `v1:1920x1080:30`. Значение по умолчанию — `v1:auto:auto`; оно используется также при отсутствии или некорректном значении. Сохранённый явный выбор сохраняется после обновления. `carlife_video_status` содержит доступный для чтения отчёт MD. Отдельно настраивать тач не требуется.

Для возврата проверенного рабочего режима вручную выберите **1280×720 / 30 FPS** и сохраните. Если открыть настройки на ГУ не получается, установите этот режим через имеющийся доступ для разработки, затем переподключите CarLife:

```sh
adb shell settings put global carlife_video_config v1:720p:30
```

Также можно вернуть сохранённые до обновления APK и MD. Для изменения этих параметров новый boot-образ или полная перепрошивка не нужны.
