# Экспериментальный CarLife HU Lab

[English](../HU_LAB.md) · [Проект](../../README.md)

Это настольный эмулятор головного устройства: он принимает видео от Android MD, декодирует H.264 и отправляет касания, «Домой» и «Назад» через CarLife. Прямой USB-тракт не использует ADB-туннель. Отдельный TCP-режим обозначен как отладочный. Это инструмент разработки, а не сертифицированная магнитола.

## Установка

Команды выполняются из корня репозитория. Рекомендуется Python 3.11+. Окно проверялось на macOS; перенос на Linux не прошёл аппаратную приёмку. Windows пока не поддерживается: блокировка владельца USB использует POSIX.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-hu.txt
# На macOS, если libusb ещё не установлен:
brew install libusb
python -m hu_lab --help
```

Зависимости: PySide6 для окна, PyAV для H.264, Pillow для сохранения кадров, системная библиотека libusb 1.0 для USB. На Android эти команды ничего не устанавливают. В тестах libx264 из PyAV создаёт искусственные изображения; личные записи экрана не нужны.

Для Ubuntu/Debian нужны системные библиотеки: `sudo apt-get install libusb-1.0-0 libegl1 libgl1 libxkbcommon0`. Даже headless CI импортирует Qt для тестов мыши и геометрии.

## Прямой USB

Сначала соберите, установите и выберите native MD по инструкции интеграции вашей платы. Бокс должен предоставлять AOA-совместимый USB device-порт; компьютер выступает USB host. HU не устанавливает MD и не настраивает Android USB gadget.

Получите список USB-устройств:

```sh
python -m hu_lab discover
```

Возьмите точный `physical_key` своего бокса. `1:2.3` ниже — пример, а не универсальный адрес. Обнаружение не открывает устройства и не захватывает интерфейсы. При запуске выбранной сессии читается серийный дескриптор, сохраняется его хеш; затем порт и серийный номер повторно проверяются при открытии транспорта.

Если бокс уже находится в accessory-режиме (`18d1:2d00` или `18d1:2d01`):

```sh
python -m hu_lab usb --device '1:2.3' \
  --width 1280 --height 720 --fps 30 --duration 600
```

Если бокс ожидает, что host инициирует переход в AOA:

```sh
python -m hu_lab usb --device '1:2.3' --aoa-start \
  --width 1280 --height 720 --fps 30 --duration 600
```

`--aoa-start` явно разрешает одну последовательность AOA-запросов. Она может отключить USB ADB, поэтому сохраните независимый способ разработки/возврата для своей платы. Автоматического отката USB-режима, перезагрузки, отключения драйвера, USB-reset и смены конфигурации нет. Неудачный или частично выполненный старт фиксируется и не повторяется внутри этой сессии. Reconnect подключается к accessory-режиму без повторного AOA start. Блокировка физического порта исключает двух одновременных владельцев HU.

Результат по умолчанию сохраняется в новый каталог `runs/<UTC timestamp>`. Параметр `--output runs/my-trial` задаёт свой новый каталог; существующие каталоги не перезаписываются. Закройте окно для остановки либо задайте `--duration`. Для декодирования без окна добавьте `--headless`.

## Окно и ввод

Мышь отправляет одно касание через CarLife. Кнопки Home, Back, Pause, Resume, Reset и Reconnect используют текущую протокольную сессию. Reset отбрасывает старое видео по номеру поколения и ждёт новые SPS/PPS и IDR. После Reconnect ошибки предыдущих сессий остаются в итоговом отчёте.

`--width`, `--height` и `--fps` задают запрос видеорежима. По умолчанию другой размер в ответе MD вызывает явную ошибку; `--allow-mode-fallback` разрешает принять другой корректный режим. Ввод согласован с принятым размером видео. `--display-policy fit` сохраняет изображение целиком; `crop` заполняет окно с обрезкой краёв. Эти параметры не меняют Android DPI. `--rotation 0|90|180|270` поворачивает изображение и координаты ввода согласованно.

По умолчанию выбран `--touch-profile legacy-single`. `legacy-dual` (pointerx/pointery) и `action3-multi` — явно выбираемые лабораторные форматы для совместимого MD. Их поддержка в эмуляторе не доказывает передачу координат второго пальца конкретной магнитолой. Псевдо-мультитач не создаётся.

## Отладочный TCP

Для одного мультиплексированного TCP-потока MD при необходимости отдельно настройте forward на его фактический порт:

```sh
adb -s YOUR_DEVICE forward tcp:LOCAL_PORT tcp:MD_PORT
python -m hu_lab tcp --host 127.0.0.1 --port LOCAL_PORT --duration 60
```

Замените значения в верхнем регистре своими. HU сам не вызывает ADB, не запускает Android-процессы и не выбирает бокс. Этот режим отмечается как `DEV_STREAM_OVER_ADB` и не считается проверкой прямого USB. Это также не старый CarLife-транспорт с шестью TCP-соединениями.

## Доказательства и автономные тесты

Сохраняются ограниченные по объёму `trace.jsonl`, `rx.bin`, `tx.bin`, `video.h264`, PNG-кадры и `summary.json`; окно добавляет `gui-summary.json`. USB-запуск сохраняет выбор устройства и события транспорта. Записи могут содержать экран, касания и метаданные устройства — проверьте их перед публикацией. Сырые захваты в репозиторий не включены.

```sh
python scripts/test_host.py --core  # 78 тестов на стандартной библиотеке, без устройства
python scripts/test_host.py         # 97 тестов, включая Qt/PyAV, без устройства
python -m hu_lab replay runs/YOUR_RUN/rx.bin
```

В экспорт включены проверки точных байтов протокола, фрагментации, ограниченных очередей, геометрии, жизненного цикла касаний, частичных USB-передач/start/reconnect, гонки RESET и декодирования первого статического кадра до EOF. Видеоданные создаются во время тестов. Это автономные регрессии, а не доказательство совместимости со всеми боксами и ГУ.

Профиль аутентификации — `SYNTHETIC_NO_AUTH_V1`, область совместимости двух компонентов проекта — `SELF`. Неизвестные запросы аутентификации/шифрования завершаются явной ошибкой. Аудио, микрофон, голосовое управление и старый транспорт с шестью TCP-соединениями не реализованы. Encoder PTS, получение кадра на компьютере и завершение Qt paint учитываются отдельно; ни одна из этих метрик сама по себе не измеряет задержку от пальца до физического экрана.
