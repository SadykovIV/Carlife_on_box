# USB call lab2 — experimental Magisk build

**This build has NOT been tested with an automotive head unit, including Honda.** Validation so far is limited to the development box and direct-USB Mac HU tests with generated audio. Real HU microphone, SIM calls and Internet/VoIP calls remain unverified.

## Changes

- Added experimental two-way USB call audio and Android application microphone routing, without a Bluetooth audio dependency.
- Integrated separate music, navigation-prompt and assistant audio paths with microphone ownership and cleanup.
- Removed repeated MUSIC status commands on every call audio packet; improved audio handover and reconnection.
- Fixed Mac CLI session shutdown during continuous call audio; preserved video RESET and SPS/PPS checks. The existing Mac GUI binary was not rebuilt.
- Combined supported TBox Ultra initial installation, updates, OEM protocol/video settings and rollback into **one Magisk ZIP**. Default video remains **Requested by head unit**.

**Checked:** 56 MD JVM suites, 133 host tests; generated USB duplex, mute/unmute, music recovery, native video RESET and host-session reconnect. Clean installation on a second physical box and full car acceptance are still pending. Earlier Honda results do not apply to this exact build.

## Install / rollback

For the supported **TBox Ultra 1 / SM6350 / Android 15** profile with existing Magisk/root, download only `Carlife_on_box-TBox-Ultra-2026.10.16-usb-call-lab2.zip` as the installer and verify `SHA256SUMS`. In Magisk: **Modules → Install from storage → select ZIP → reboot**. Keep stable power. Initial installation backs up and patches this box's own active boot; compatible updates retain the existing integration and saved choices. It is not a universal installer for arbitrary boxes.

For package rollback, run in a rooted Android terminal or existing ADB shell, wait for success, then reboot:

```sh
su -c '/data/adb/magisk/busybox sh /data/adb/carlife-package/control.sh rollback'
```

Rollback restores the first saved package baseline, not necessarily the immediately preceding update. On an earlier manual integration, its existing boot integration remains. Read the [English installation and rollback guide](https://github.com/SadykovIV/Carlife_on_box/blob/v2026.10.16-usb-call-lab2/docs/MAGISK_INSTALLER.md) for prerequisites and the exact branch-specific behavior.
